GIRARD PEINTURE — V4
======================

Site vitrine en une seule page verticale, responsive mobile + ordinateur.

Installation GitHub Pages :
1. Crée un dépôt GitHub.
2. Mets index.html à la racine du dépôt.
3. Settings > Pages > Deploy from a branch > main > /root.
4. Enregistre. GitHub publiera automatiquement le site.

Le numéro est 06 18 51 78 66.
Le bouton de devis utilise mailto:contact@girard-peinture.fr ; remplace cette adresse
par ton adresse réelle si nécessaire.
Les photos sont chargées depuis Unsplash. Pour un site 100% autonome, remplace-les
plus tard par tes propres photos dans un dossier images/.
